# AI 도슨트 시작 데이터

1400~1900년에 제작된 시카고 미술관 유럽 회화 100점과 해설용 문서를 담은 초기 데이터입니다. 데이터와 원문은 영어이며 한국어 번역이나 AI 생성 해설은 아직 포함하지 않습니다.

초기 수집본은 작품 해설 100건, 작가 소개 57건, 시대·사조 소개 14건으로 총 171개 문서입니다. 작품 100점 모두 세 종류의 문서에 연결됩니다. 작가와 사조 문서는 여러 작품이 공유합니다.

OpenLearn 강좌 3종의 저자 해설 선별본 **50개 문서(274개 문단)**를 추가하여 현재 `documents.json`에는 총 **221개 문서**가 있습니다. 근세 유럽 입문 19개, 네덜란드 황금시대 회화 13개, 계몽주의 18개입니다. 추가 문서는 영어 원문이며, 기존 171개 문서는 보존합니다. 현재 채팅은 이 문서들을 작품 범위로 검색해 RAG 답변에 사용하며, 실제 인용한 문서의 출처·이용 조건·발췌를 표시합니다.

각 강좌의 Acknowledgements에서 **CC BY-NC-SA 4.0** 및 제3자 자료의 예외를 확인했습니다. 저자 해설 본문을 장·절별로 선별하며 다음 항목은 제외합니다.

- 이미지·도판 설명·사진 크레디트·오디오/비디오와 대본
- 외부 인용문·인용의 이어지는 문단·출처 표시·짧은 시구
- 인용 표현이 섞인 문단 전체. 짧은 용어 인용도 보수적으로 제외하므로 원문 전체를 수집한 것은 아닙니다.
- 활동/연습의 지시문·제공된 발췌문·학습 안내·참고문헌·용어집
- 근세 유럽 강좌의 **Activity 4 전체**: Methuen/Taylor & Francis 권리 표시가 있는 부분
- 네덜란드 강좌의 Fromentin 번역 발췌문 등 별도 권리 표시가 있는 자료

Discussion에서는 같은 문단 필터를 통과한 **강좌 저자 자신의 해설만** 남깁니다. 새 절에 재사용할 수 있는 본문이 300자 미만이면 그 절도 제외합니다. 중간 문단이 빠진 발췌본이므로 완전한 원문 장으로 해석하면 안 됩니다. 원문에 없는 연결 문장이나 한국어 번역, AI 생성 설명은 추가하지 않았습니다.

새 문서의 `kind`는 `historical_context`, `source_type`은 `openlearn`입니다. `related_artwork_ids`는 비워 두고, 특정 작품의 제작 원인이나 사조와 자동 연결하지 않습니다. `context_tags`는 강좌 범위를 나타내는 검색 준비용 분류입니다.

RAG에서는 원본 연결 필드를 수정하지 않고 제작 시기·네덜란드 관련 지역 정보로 OpenLearn 검색 후보를 제한합니다. 검색된 강좌는 일반 시대 배경임을 모델과 화면에 알립니다. 자세한 범위와 검색 방식은 프로젝트 README의 RAG 검색 방식을 참고합니다.

각 문서는 저자·원문 URL·강좌 URL·수집일·라이선스·라이선스 확인 페이지·출처 표기·변경 내역을 보존합니다. `passages`와 `source_locator`는 선택한 문단의 원문 위치와 해시를 기록합니다. 제외한 자료는 공개 데이터에 본문을 복제하지 않고, 수집 보고서에 위치·사유·해시만 남깁니다.

일반 HTTP 요청과 공식 다운로드 경로가 봇 확인 응답을 반환하여, 이번에는 공개 공식 페이지를 웹 리더로 읽어 수집했습니다. 차단을 우회하거나 인증을 사용하지 않았습니다. 원문 페이지 텍스트 스냅샷은 검증용으로 `.cache/openlearn/snapshots.json`에만 보관하며, 이 캐시에는 제외 대상이 포함되어 있어 배포하지 않습니다. 원문 위치는 이 스냅샷의 줄 번호이며 HTML 줄 번호나 PDF 쪽 번호가 아닙니다.

라이선스가 다른 기존 문서와 혼합되어 있으므로 데이터 전체에 하나의 라이선스를 적용하지 않습니다. **OpenLearn 레코드는 비영리 사용 조건을 유지**하고, 출처·저자·라이선스 링크·변경 사실을 제공해야 합니다. 번역·가공한 자료를 배포하면 동일 라이선스 조건을 반영해야 합니다. 강좌 안의 제3자 자료는 이 허용에 포함하지 않습니다. 기관이나 저자가 이 프로젝트를 승인했다는 표시는 하지 않습니다.

## 수집 기준

- 시카고 미술관의 `Painting and Sculpture of Europe` 부서 소장 회화
- `is_public_domain=true`, 이미지 ID 존재, 작가명 존재
- 작가 소개를 연결할 수 있도록 문화권만 표기된 항목 등 일부 익명 귀속 작품 제외
- HTML 태그를 제거한 작품 설명이 300자 이상
- 제작 시작 연도가 1400~1900년
- 아래 사조·시대 소개 문서에 연결할 수 있는 미술관 태그가 하나 이상 있는 작품
- 1400~1599년 20점, 1600~1699년 20점, 1700~1799년 20점, 1800~1900년 40점을 우선 선정
- 특정 구간의 적격 후보가 부족하면 다른 구간의 적격 후보로 100점을 채움. 실제 분포는 수집 보고서 참고
- 작품의 사조는 미술관 `style_titles` 값을 그대로 보존하며 제작연도로 추정하지 않음

출처의 검색 순서와 내용은 바뀔 수 있습니다. 같은 환경에서는 `.cache/art-data/`의 원본 응답을 재사용합니다. 원본 응답별 URL과 수집일도 캐시에 저장합니다.

## 세 가지 설명 연결

1. **작품 설명:** `artwork_document_id`로 해당 작품의 미술관 해설을 찾습니다. 작품 100점 모두 개별 해설이 있습니다.
2. **작가 설명:** `artist_document_ids`로 작가의 위키백과 소개를 찾습니다. 미술관 표기와 위키백과 표기가 다른 일부 작가는 스크립트의 명시적 별칭표로 연결합니다. 동명이인·귀속 관계는 수동 검토가 필요합니다.
3. **시대·사조 설명:** `style_document_ids`로 미술관 태그에 대응하는 소개 문서를 찾습니다. `style_tags`에는 사조 외에도 세기·기법 등이 섞여 있습니다. 연결이 없는 작품의 사조를 임의로 채우면 안 됩니다.

작가·사조 소개는 대부분 위키백과의 도입부입니다. 짧은 작가 도입부는 전체 본문으로 보완합니다. 문서의 `content_scope`로 범위를 구분합니다. 상세한 질문은 추가 문서를 검색해야 합니다.

`Workshop of ...` 귀속은 원문 그대로 남깁니다. 연결된 작가 소개가 공방 작품을 거장의 친필 작품으로 확정하는 근거가 되지는 않습니다.

위키백과 소개는 영어 원문이며, 한국어 `title_ko`·`artist_ko`는 아직 `null`입니다. 한국어 이름은 검증된 표기를 추가하고, 번역한 문서는 원문과 분리해 번역 여부·원문 ID를 기록하는 방식으로 확장합니다.

## 이미지

이미지 파일을 내려받지 않고 공식 IIIF 이미지 URL을 저장했습니다.

- `image_url`: 상세 화면용 843px 이미지
- `thumbnail_url`: 목록용 400px 이미지
- `image_alt`: 미술관이 제공하는 대체 텍스트

초기 수집 시 대표 이미지 URL이 HTTP 403을 반환했습니다. 실제 프론트 연결 과정에서는 `image_fallbacks.json`에 동일 작품의 Commons 공개 복제본을 추가했습니다. 작품 ID·소장번호·Wikidata P4610으로 일치 여부를 검증하며, 이미지 파일 원문과 라이선스를 보존합니다. 현재 97점에 대체 경로가 있고, 나머지 3점은 원본 URL을 사용합니다. 실패 시 작품 정보와 미술관 원문 링크를 유지합니다. 상세 재수집 방법은 프로젝트 README를 참고합니다.

## 다시 만들기

프로젝트 루트에서 실행합니다. Python 표준 라이브러리만 사용하며 API 키나 LLM 호출이 필요하지 않습니다.

```powershell
python scripts/prepare_art_data.py
```

스크립트는 호출 간격을 두고 단일 스레드로 요청하며, 캐시와 재시도를 지원합니다. 프로젝트 `.env`에 유효한 `WIKI_CONTACT`가 있으면 User-Agent에 사용합니다. 연락처나 API 키를 출력하거나 결과 데이터에 저장하지 않습니다.

완료 시 항목 중복, 문서 중복, 문서 ID 연결, 필수 정보, 원문 길이와 출처·라이선스 존재 여부를 검사합니다. 수집·정규화와 문서 연결을 수행하며 임베딩 색인이나 RAG 답변 생성은 수행하지 않습니다.

기존 미술관/위키백과 수집 스크립트는 `openlearn_documents.json`의 검증된 선별본을 보존하여 최종 `documents.json`에 함께 저장합니다. OpenLearn 원문을 다시 요청하지 않습니다.

선별본을 기존 데이터에 중복 없이 다시 합치려면 실행합니다. 네트워크 요청은 없습니다.

```powershell
python scripts/prepare_openlearn_data.py --merge-only
```

이번에 보관한 로컬 원문 스냅샷에서 선별 과정을 재현하려면 실행합니다.

```powershell
python scripts/prepare_openlearn_data.py --snapshots .cache/openlearn/snapshots.json
python -m unittest discover -s tests -v
```

새 스냅샷으로 갱신할 때는 강좌별 이용조건과 제3자 예외를 다시 확인합니다. 스크립트는 원문 누락과 중복 ID를 검사하며, 봇 확인을 우회하는 자동 수집 기능은 제공하지 않습니다.

## 요구사항에 연결하기

- **메타데이터 컬렉션:** 작품당 `search_text` 한 건, 고정 ID는 `aic:<작품 ID>`
- **외부 문서 컬렉션:** `documents.json`의 `text`를 청킹하고 제목·원문 URL·출처 유형·라이선스·관련 작품 ID를 함께 저장
- 하나의 작가/사조 문서는 여러 작품에 공유될 수 있습니다. 작품별 청크로 복제한다면 `<작품 ID>:<문서 ID>:<청크 순번>`처럼 충돌을 막습니다.
- 작품별 대화에서는 선택한 작품 ID로 근거 범위를 제한합니다.
- 사용자의 질문에 따라 검색어를 추출하고 후보를 LLM으로 선별·수집하는 F2003~F2004 파이프라인은 이후 구현해야 합니다. 이 데이터는 초기 문서 묶음이며 그 기능의 완성본은 아닙니다.

정확한 연결 건수와 누락 항목은 `collection_report.json`에서 확인합니다.
